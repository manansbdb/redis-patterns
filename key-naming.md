# Key Naming / Nomenclatura de Keys

## English
- Use colons: `app:env:entity:id:field` → `shop:prod:user:42:profile`
- Include version when schema of value changes: `...:v2`
- Avoid huge key cardinality explosions without TTLs.

## Português
- Use dois-pontos: `app:env:entity:id:field` → `shop:prod:user:42:profile`
- Inclua versão quando o schema do valor mudar: `...:v2`
- Evite explosão de cardinalidade sem TTLs.
